# Framelet 0.1.0 — Capture foundation

Original build date: 2026-10-30. Imported to GitHub on 2026-11-01; this is not a claim that the GitHub release was published on the original build date.

- Area, visible-window, display and repeat-area capture with configurable hotkeys.
- Floating preview, copy/save, up to eight pins and local capture history.

Historical capture build. Use 0.5.2 for the last locally verified capture/annotation baseline.

Download the **win-x64 ZIP** for the portable app, or the **source ZIP** for the archived source. Extract the full Windows folder and keep the EXE/DLL/JSON files together. Requires .NET 10 Desktop Runtime x64. Quit earlier Framelet copies before launching.

The uploaded ZIPs are the original local build archives, not rebuilt historical binaries. ZIP integrity, manifests and SHA256 were checked for this import; historical native tests were not rerun. Source tags were reconstructed in chronological order from those source archives, using the actual import commit date. Reference installers/media, private logs, local history and test captures are excluded.

See [the download log](https://github.com/hooksha-DA7/framelet/blob/main/RELEASES.md) for all versions. `SHA256SUMS.txt` covers the two uploaded ZIPs.
