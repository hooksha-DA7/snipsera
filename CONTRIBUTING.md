# Contributing to Snipsera

Thanks for your interest in Snipsera.

- **Bugs and ideas:** use the [issue forms](https://github.com/hooksha-DA7/snipsera/issues/new/choose). Check for an existing issue first, and remember that issues are public.
- **Questions:** start with the [user guide](docs/USER-GUIDE.md) and [snipsera.com/support](https://snipsera.com/support/).
- **Code:** see [Build from source](docs/DEVELOPMENT.md). Keep changes focused, follow the existing style and run the checks described there. Please open an issue to discuss larger changes before starting.

By contributing, you agree that your contribution is licensed under the project's [MIT licence](LICENSE).
