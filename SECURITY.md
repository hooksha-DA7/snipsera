# Security policy

Snipsera runs locally: it has no account, server or cloud service, and it only contacts GitHub or Microsoft Store for optional update checks.

## Reporting a problem

Please report security problems privately through [GitHub's private vulnerability reporting](https://github.com/hooksha-DA7/snipsera/security/advisories/new) rather than a public issue. Include the Snipsera version (Settings > About), how it was installed and steps to reproduce. Don't attach private screenshots or recordings.

You'll get a reply as soon as possible. Fixes ship in a new version through Microsoft Store and GitHub Releases.

## Supported versions

Only the latest release receives fixes. Microsoft Store installations update automatically; GitHub installations can check for updates in Settings > Updates.
