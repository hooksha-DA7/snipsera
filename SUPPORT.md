# Snipsera support

For bugs and feature requests, [open an issue](https://github.com/hooksha-DA7/snipsera/issues). Include the app version, Windows version, what you expected and the steps that reproduce the problem. Screenshots are useful when they contain no private information.

For capture and recording instructions, see the [user guide](docs/USER-GUIDE.md). Downloads and known release limitations are in the [release log](RELEASES.md).

Never post passwords, API keys, private recordings or unredacted customer information in a public issue. Screen capture can include notifications and other apps visible in the selected area, so review any attachment first.
